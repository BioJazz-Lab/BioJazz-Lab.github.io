Which network structures can produce a given dynamic behavior, and how
readily does evolution find them? We developed
[BioJazz](https://doi.org/10.1093/nar/gkv595), a framework for the *in silico*
evolution of cellular networks with unbounded complexity using rule-based
modeling, and used it together with mathematical analysis to study
signaling motifs, such as multistability arising from multi-state enzymes
([J. R. Soc. Interface, 2016](https://doi.org/10.1098/rsif.2016.0524)) and
enzyme sequestration as a tuning point for response dynamics
([PLoS Comput. Biol., 2016](https://doi.org/10.1371/journal.pcbi.1004918)).
